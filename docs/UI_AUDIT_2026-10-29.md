# Interface audit — 29 October 2026

Scope: the Liquid Glass interface and editing changes following 0.3.8.1, released in 0.3.9.

## Corrected findings

- Native month mode registered Ctrl+N and Ctrl+F in both the window and embedded calendar. The window now owns desktop shortcuts; standalone calendar shortcuts remain available. Ctrl+L opens the desktop date dialog, and modal dialogs block background creation/search actions.
- Removing the embedded header made appearance controls unreachable. Settings now provides persistent, app-wide accent and opacity controls. Invalid values and failed writes preserve active settings. The opacity range matches the active light/dark limits.
- Date/time picker palettes and text selection did not follow the new accent. Palette roles now propagate to the desktop picker and menu controls, preserving standalone defaults.
- Horizontal week scrolling hid the hour labels. A frozen time axis and corner keep time labels aligned and visible. The Settings scrollbar is explicitly anchored to the right edge.
- Closing a popup during its opening animation reset it to full opacity and scale. Exit transitions now start from the current rendered state.

## Validation

144 Python tests include appearance round trips, invalid values and write failures. Actual Qt checks exercise keyboard dispatch, modal guards, visible settings controls, interrupted animation frames, scrollbar dragging before mouse release and frozen-axis geometry. Eight JavaScript suites, the isolated widget editor and a temporary-database smoke launch cover the shared components. Screenshots use synthetic records at 980×680 and 1280×860 in light and dark themes.

An independent agent reproduced the settings/picker/animation defects and rechecked the corrections with separate isolated Qt scripts. Offscreen checks do not establish that every live desktop environment is bug-free.

## Merge draft follow-up

Merge now uses the validated current editor values in its preview and final atomic write. Candidate events match the edited date and all-day mode. The original saved snapshot remains separate for identity checks, source removal and cancellation of the original series occurrence. Modified command identities, tasks and entire recurring series are rejected. A moved occurrence can merge with a distinct occurrence of the same series on its target day.

Cancel leaves stored records unchanged and keeps the editor draft. A successful merge selects its destination date. One Undo restores both original saved sources without an intermediate draft save. Tests cover edited content, date/all-day changes, invalid input, concurrent source changes, identity tampering and future-repeat preservation. Source records are rechecked inside the SQLite write transaction, including identical concurrent series cancellations with different occurrence draft IDs, preventing duplicate merge results.
