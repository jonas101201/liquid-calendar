# Liquid Calendar 0.1.0 Beta 1

First public beta of a local calendar and task planner for Fedora/KDE Plasma.

**Version:** 0.1.0-beta.1 · **Tag:** v0.1.0-beta.1 · **Language:** English · **License:** GPL-3.0-or-later

## Highlights

- Today overview, weekly timeline, monthly calendar and agenda.
- Undated tasks, flexible search, categories and planning filters.
- Repeating events, individual occurrences, reminders and free-time planning.
- Shared local data with an optional Plasma widget, backups and conflict detection.
- JSON backup/import and ICS event export.

Download the source archive, extract it, then run `python3 installieren.py`. Use `--with-widget` for the optional Plasma companion. The installer downloads dependencies from PyPI; this archive is not a bundled binary/offline installer.

This is a prerelease. Fresh-account installation testing was skipped at the maintainer's request. See KNOWN_ISSUES.md for supported scope and TESTING.md for actual checks. No cloud sync or Windows/macOS support is claimed.

Checksums accompany the download. They detect changed/corrupted downloads but are not cryptographic signatures from a verified publisher.
